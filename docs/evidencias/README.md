# Evidências

Prints e GIFs de cada funcionalidade entregue. Esta pasta é o seu seguro contra
a demo ao vivo falhar no dia da apresentação — e é o que permite mostrar a uma
banca uma tela que está temporariamente quebrada.

## Convenção de nome

```
RF-001-cadastro-agendamento.png
RF-001-cadastro-erro-data-passada.png
US-003-fluxo-completo.gif
```

Prefixo com o ID do requisito ou da história, depois o que a imagem mostra.

## O que capturar para cada funcionalidade

1. A tela em estado inicial (vazio)
2. A tela em uso, com dado preenchido
3. **Um caso de erro tratado** — é o que mais impressiona a banca
4. A tela em 360px de largura, provando a responsividade

## Como gravar um GIF

- Windows: Ferramenta de Captura (Win+Shift+S) grava vídeo; converta para GIF, ou
  deixe em MP4 mesmo — serve igual
- Alternativa em qualquer sistema: grave a tela e coloque o arquivo aqui

Capture assim que a funcionalidade ficar pronta. Deixar para a semana da entrega
é como garantir que não vai acontecer.
